# 🎮 坦克大战 · Battle City

一个用原生 HTML5 Canvas 编写的经典《坦克大战》网页游戏，单文件、零依赖，双击即可游玩。

## ✨ 功能特性

- 🕹️ 经典玩法：驾驶坦克保卫基地（鹰），消灭所有敌方坦克
- 🧱 丰富地形：砖墙（可摧毁）、钢墙、河流（坦克不可通行）、树林（隐藏坦克）
- 👾 四种敌人：基础、快速、重装（2 血）、装甲（3 血）
- ⭐ 道具系统：火力升级（★）、基地护盾（🛡）、加命（♥）、清屏炸弹（💣）
- 💥 打击反馈：爆炸动画、音效（Web Audio 合成）
- 🏆 无限关卡：3 张地图循环，敌人数量随关卡递增
- 📱 移动端支持：触屏虚拟摇杆 + 开火按钮

## 🎮 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` | 开火 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |
| `Enter` | 开始 / 下一关 |

## 🚀 如何运行

**方式一：直接打开**

双击 `index.html`，或用浏览器打开即可。

**方式二：本地服务器（可选）**

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

**方式三：GitHub Pages**

在仓库 Settings → Pages 中将分支设为 `main`、目录设为 `/ (root)`，即可在线游玩。

## 🧱 游戏规则

- 保护屏幕下方中央的**基地（鹰）**不被敌人摧毁，同时消灭全部敌方坦克即可过关。
- 玩家初始有 3 条命，被击中会损失一条命并在原地复活（火力降 1 级）。
- 基地被摧毁或生命耗尽即游戏结束。
- 每关通关奖励 500 分，敌人越多分数越高。

## 🛠️ 技术栈

- 原生 HTML5 + CSS3 + JavaScript（Canvas 2D）
- 无任何外部依赖
